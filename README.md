# SoEasy DICOM Web

Browser / iPad / iPhone version of SoEasy DICOM Viewer: 2D, cine, DSA, MPR, layouts with reference lines and 3D
volume rendering. Open the site, then (on iPad / iPhone) Share → Add to Home Screen to use it offline.

All DICOM processing runs in the browser. Images are never uploaded; the app sends no analytics.

Personal visualisation aid — **not a certified diagnostic device**.

This repository holds only the built web app (published with GitHub Pages).
